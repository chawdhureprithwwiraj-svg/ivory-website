Installing the app

1. Tap the download button when it appears. The file is large, so use Wi-Fi if you can.

2. When it has finished, open the file. If Android asks, allow your browser to “install unknown apps” (a one-time switch in Settings).

3. Because the app is shared directly and not through Google Play, Android may show a warning such as “unknown developer”. Continue only if you downloaded the file from this official page.

4. Open Ivory and sign in. Android phones only.
